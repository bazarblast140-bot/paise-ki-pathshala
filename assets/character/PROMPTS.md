# Character generation prompts — THE MONEY RULE

Use the SAME base description for all 6. Change only the pose line.
Transparent or pure white background. Full body. No text, no watermark, no extra people.

## BASE (prefix every prompt)

```
Clean 2D cartoon illustrator style, finance explainer character,
man about 30 years old, short neat black hair, light skin, friendly confident expression,
white lab coat over white shirt, thin black tie, dark navy trousers, simple black shoes,
full body visible, plain pure white background, no text, no logo, no shadows under feet,
consistent character design sheet, high quality, sharp lines, flat colors
```

## 6 POSES

### 1) neutral.png
BASE + `, standing facing camera, arms relaxed at sides, slight smile, neutral welcoming pose`

### 2) point.png
BASE + `, standing, right arm extended pointing to the right side of frame, left arm relaxed, explaining pose, slight smile`

### 3) point_up.png
BASE + `, standing, right arm raised pointing upward, enthusiastic teacher pose, open smile`

### 4) think.png
BASE + `, standing, right hand on chin thinking, slight head tilt, curious thoughtful expression`

### 5) warn.png
BASE + `, standing, one palm raised in stop/warning gesture, serious but calm expression, caution pose`

### 6) ok.png
BASE + `, standing, giving a clear thumbs-up with right hand, warm confident smile, positive affirmation pose`

## Tips
- Generate all 6 with the same seed / reference image if the tool allows (character consistency).
- Export PNG, ideally transparent background (or remove white later).
- Crop similarly so the character height matches across poses.
- Drop files into this folder with exact names above.
